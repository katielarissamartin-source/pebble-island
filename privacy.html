Privacy and learning data

Prototype information — updated 23 October 2026. This explains the current technical behaviour of the Pebble Island demonstration. It is not a substitute for a reviewed commercial privacy policy.

Learning progress stored on the device

Pebble Island stores the two child profiles and game state in your browser storage. The newer Learning Path records which lessons are attempted, answers correct without help, review due dates, teacher-pilot assignments and local feedback. Those new pathway records are stored in your browser. If the optional family cloud is connected, the original app may also include these records in family-cloud backups; a backup restore can transfer them to another device.

Other game information such as settings, game scores and rewards is also stored locally. Clearing browser data may remove it. Adults can export a JSON backup or a CSV practice report from the grown-up dashboard.

Optional family-cloud features in the original game

Older Pebble Island game features include an optional family-code connection. If a family code is connected, game event records, timestamps and optional device names may be sent to the existing Supabase service for family progress and messaging. An additional family-cloud backup feature can store a snapshot of the full game state, including new Learning Path reviews, on this external service. Do not connect the family cloud unless an adult understands and wants the feature.

This prototype does not currently offer a managed family account system, a child-data cloud backup, or a school account service.

Hosting and external resources

Vercel hosts the website and may process ordinary technical request logs. The app loads some fonts from Google Fonts; those requests are made to Google. Browser speech output is provided using the device/browser speech facilities. No payment checkout has been activated by the new Learning Path.

Managing and removing records

Adults can review, export or clear individual children's curriculum records from the Grown-up area, under Privacy & settings. Clearing only curriculum data leaves older island game progress in place. For all local records, use the browser's site-data deletion controls. Previously transmitted family-cloud game events and backup snapshots will not be erased by clearing local browser storage; deletion of server records needs a separately implemented administrator process.

Children's privacy and school use

Do not enter sensitive health information, addresses, identity numbers or school details into profiles or free-text fields. The school preview is only an on-device prototype and is not represented as approved for use by the Queensland Department of Education. Before public commercial launch, a responsible entity, contact mechanism, Australian privacy review, retention procedures and appropriate account security must be established.
